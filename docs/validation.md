  Computer Use에서 앱은 확인했지만 화면 접근 승인 대기 시간이 만료되어 UI 검증을 수행하지 못함.
  사용자 Flow Launcher에는 플러그인을 설치하거나 설정을 변경하지 않았음.
- 실제 네이버 인증값을 사용한 성공 응답과 권한/사용량 제한. 실제 키를 제공받거나 읽지 않았음.
- GitHub Actions의 원격 실행. 워크플로만 준비했으며 push/게시하지 않았음.

## 사용자가 수행할 수동 확인

1. README의 설치 방법으로 ZIP을 설치하고 Flow Launcher를 재시작한다.
2. `nm` 입력 시 사용 예시, `nm 강남 카페` 입력 시 인증값 설정 안내를 확인한다.
3. 플러그인 설정에 본인의 인증값을 저장하고 검색한다.
4. 최대 5개 결과의 이름·분류·주소, Enter 시 네이버 지도 검색을 확인한다.
5. Flow Launcher 재시작 후 인증값이 유지되는지 확인한다.
